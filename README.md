# Fast Git Project

A beginner Git and GitHub practice project created to learn the basic workflow of creating a repository, making commits, connecting a remote repository, and pushing code to GitHub.

## 📚 Topics Practiced

- Git repository initialization
- Creating commits
- Adding files to Git
- Creating and switching branches
- Connecting a remote repository
- Pushing code to GitHub
- Basic Git workflow

## 🛠️ Technologies

- Git
- GitHub
- HTML5
